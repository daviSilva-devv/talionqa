# TalionQA UI Direction v0

## Feel
Welcoming, intelligent, calm and spatial. The product should feel alive without becoming noisy.

## Base palette
- Canvas: white / warm off-white.
- Primary intelligence/action: Talion purple.
- Supporting states: lavender and neutral violet-gray.
- Critical state: restrained coral/red only where necessary.
- Success: soft green, never dominant.

Exact tokens may evolve; preserve the white + purple identity.

## Product metaphor
X-Ray is a living map of the project.

Prefer:
- space over card density;
- nodes/relationships over category dashboards;
- contextual floating detail panels;
- progressive disclosure;
- useful motion showing scan/state/data flow;
- strong empty space and typography.

Avoid:
- default admin dashboard composition;
- giant permanent sidebars;
- unnecessary glassmorphism;
- rainbow gradients;
- cyberpunk/hacker visual clichés;
- fake metrics;
- decorative animation without meaning.

## Core experiences
### Discovery
Nodes appear as Talion understands the project.

### X-Ray
Healthy areas stay visually quiet. Findings create localized emphasis.

### Finding focus
Selecting a finding should reveal its path: user action / component / request / service / evidence when available.

### Diagnose
Paid diagnosis should deepen the same spatial context rather than open a disconnected report page.

## Motion
Motion communicates:
- discovered;
- scanning;
- affected;
- changed;
- resolved.

If motion does not explain a state transition, remove it.
